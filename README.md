# Página de mantenimiento

## Archivos

- `index.html`: página principal con el botón CONTACTO.
- `contacto.html`: formulario.
- `estilos.css`: estilos de ambas páginas.
- `Operario.png`: debes añadir tu imagen con este nombre exacto.

## Publicación en GitHub Pages

1. Sube los cuatro archivos a la raíz de tu repositorio.
2. En GitHub, abre **Settings → Pages**.
3. Selecciona la rama que quieras publicar y la carpeta raíz.
4. Guarda los cambios.

## Activación del formulario

El formulario usa FormSubmit para enviar mensajes a `juanlubaz@gmail.com`.

La primera vez que se envíe:
1. FormSubmit enviará un correo de activación a esa dirección.
2. Abre el correo y confirma la activación.
3. A partir de entonces, los mensajes deberían llegar al buzón.

Revisa también la carpeta de correo no deseado. La dirección aparece en el
código HTML público. Para evitar exponerla, usa el identificador cifrado que
FormSubmit ofrece después de activar el formulario o utiliza un backend propio.
